## Phase 2 — Mobile responsive

Once theming is done, audit each admin page at three viewport widths and fix anything broken:
- 375px (iPhone SE / small phone)
- 768px (iPad portrait / tablet)
- 1024px+ (desktop, current state)

Specific patterns to apply (use Tailwind responsive prefixes — `sm:`, `md:`, `lg:`):
- Multi-column card layouts → stack to single column on mobile (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3` pattern)
- Form fields with side-by-side labels → labels stack above inputs on mobile
- Buttons grouped horizontally → either stack vertically OR remain horizontal with `flex-wrap` if they fit
- Header (the dashboard title + Logout button) → stays on one line if it fits, otherwise collapses
- Tables (if any in archive view) → horizontal scroll wrapper, OR stack as cards on mobile
- Touch targets: minimum 44×44px for any tappable element on mobile (Apple HIG standard). Buttons, icons, eye-reveal toggles, copy buttons — all must hit this.
- Textareas (newsletter paste box, plan notes): full width on mobile, taller default height (at least 200px) so paste-and-review is usable from a phone
- Date pickers and select dropdowns: full width on mobile, native browser controls are fine

The admin parse-newsletter page is the highest priority for mobile because that's the daily-use page — you want to be able to paste a newsletter from a phone if needed.
